# FIXORA Voice Interaction Module

## Overview

This project implements the Voice Interaction module for FIXORA.

## Features

- Speech-to-Text
- Text-to-Speech
- Voice-based interaction
- Basic electrical fault diagnosis
- Safety response
- Continuous conversation flow

## Workflow

User Voice
↓
Speech-to-Text
↓
Fault Identification
↓
Diagnosis
↓
Text-to-Speech
↓
FIXORA Voice Response

## Technologies

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
